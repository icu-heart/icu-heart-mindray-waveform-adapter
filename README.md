# ICU-Heart Adapter for Mindray Waveform HL7 Messages

> [!WARNING]
> This project is a 🚧 work in progress 🚧; please use the code with caution. We welcome issues and pull requests with suggestions for improvement.

> [!NOTE]
> Documentation can be found at [https://icu-heart.github.io/icu-heart-mindray-waveform-adapter/](https://icu-heart.github.io/icu-heart-mindray-waveform-adapter/).

This code was developed by the [ICU-Heart Team](https://icu-heart.github.io/) at the University of Edinburgh in parternship with [NHS Lothian](https://www.nhslothian.scot/) and [DataLoch](https://dataloch.org/) (the Lothian regional Safe Haven).

Its purpose is to stream HL7 messages of continuous waveform monitoring from a [Mindray eGateway](https://www.mindray.com/en/products/it-products/egateway) and convert them to a common message format suitable for input to an [AtriumDB](https://github.com/LaussenLabs/atriumdb) waveform database.
